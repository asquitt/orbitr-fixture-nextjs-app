# Next.js app router fixture

A test fixture for Orbitr (EVAL-01c, https://github.com/asquitt/orbitr/issues/1444). A Next.js app router site (static export to `out/`) built by a Git-connected Cloudflare Pages project. Seeded from the `orbitr-canary-nextjs-20260228` canary's `app/` tree and `next.config.mjs`. Contains no real business data.
